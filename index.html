HOW IT WORKS

One local proxy, one line to change

Toknife speaks the OpenAI protocol. Your code, prompts and model stay the same — only the endpoint points at your machine.

01

Point to the local proxy

Set your client’s base_url to Toknife on localhost. No SDK swap, no new account.

02

Compress on your machine

Input and output are optimized locally before they reach the model and after they return.

03

Pay less, keep quality

Same model, same answer path — with a smaller, measurable token count on the usage field.

# before — requests go straight to the provider
client = OpenAI(api_key=os.environ["API_KEY"])

# after — route through Toknife's local OpenAI-compatible proxy (default port 8001)
client = OpenAI(base_url="http://127.0.0.1:8001/v1", api_key=os.environ["API_KEY"])
# → identical prompts and model, fewer billed tokens; a dashboard runs on :8121
